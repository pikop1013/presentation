Place slide images in this folder.

Usage:
- Put files under `public/images/`
- Reference them from slide data with `imageSrc: '/images/your-file.png'`
- Optional alt text can be added with `imageAlt`

Example:
```ts
placeholders: [
  {
    label: 'Screen Shot',
    imageSrc: '/images/slide-04-tool-screen.png',
    imageAlt: 'Tool screen shot',
  },
]
```
